# 怎么验证（每个里程碑都跑这一套）

> 你不需要懂代码。只需要跑两条命令、看两样东西。

## 一、两条命令

在项目根目录打开终端（Windows：在 `D:\prd-pipeline` 文件夹地址栏输入 `powershell` 回车），依次执行：

```
npm test
```
**期望**：出现 `Tests ... passed`，且没有 `failed`。

```
npm run smoke
```
**期望**：最后一行输出 `SMOKE PASS`。

> 首次执行如果提示缺少依赖，先跑一次 `npm install`，再重试。

## 二、失败了怎么办

把终端里报错的那段整体复制发我即可，不用自己排查。

## 三、想看产物长什么样

打开 `examples/sample-prd.md`——这是工具**真实生成**的一份 PRD（含流程图、修订记录、表格），能直观看出产物质量。

## 四、这两条命令各在验什么

| 命令 | 验证内容 | 是否需要联网 |
|------|---------|:----:|
| `npm test` | 契约校验 + 纯函数 + 工具集成（不依赖外部） | 否 |
| `npm run smoke` | 真实 MCP 全链路：初始化 → 选预设 → 生成 → 出图 → 落库 | 否 |

两条都过，就说明"骨架是通的、且没被改坏"。
